# CGRAS 2025: Modelling Coral Object Detection in CCVS

This document explains the semantics of coral counting and coral object classes in CCVS.

## Counting Coral Objects

The current version of CCVS is designed to count three types of objects: alive corals, dead corals, and other objects. Other objects refer to those that are not corals, alive or dead, but of interest to the users.
